About Chomp

A tool for exploring restaurant data in any city around the world

What is Chomp?

Chomp lets you search any city and pull up restaurant data from OpenStreetMap — things like cuisine type, phone numbers, websites, and addresses. It's useful for getting a quick snapshot of the dining scene anywhere in the world without needing a paid API.

I built it mainly to see how much useful data OSM actually has for restaurants, and it turned out to be pretty solid for most major cities.

How It Works

1. Location Input: You type in a city or address and set the search radius (100m to 50km).

2. Geocoding: Nominatim converts the location name to lat/lon coordinates.

3. Data Fetch: The Overpass API queries OSM for all restaurants within that radius, pulling whatever tags are available — name, cuisine, phone, website, address, etc.

4. Processing: The backend parses the response, calculates stats, and saves everything to SQLite.

5. Display: Results come back as JSON and the frontend renders the charts and table.

Tech Stack

Backend: Flask (Python) — handles routing, geocoding requests, Overpass API calls, and SQLite storage.

Frontend: Plain HTML, CSS, and vanilla JS. No frontend framework, kept it simple.

Charts: Chart.js for the bar and doughnut charts.

Data: OpenStreetMap via Nominatim (geocoding) and Overpass API (restaurant data).

About This Project

This was built as a final project for CS50x. The goal was to put together a full-stack web app that actually does something useful — real API integration, a database, and a frontend that makes the data readable. Ended up being a good excuse to dig into how much (and how little) data OSM has depending on the city.
